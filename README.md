# img_to_pdf
# 📸 Image to PDF Converter

A simple Python project that converts JPG, JPEG, and PNG images into a single PDF file. The program automatically scans the current folder for images and generates a PDF using the FPDF library.

## Features
- Converts multiple images into one PDF
- Supports JPG, JPEG, and PNG formats
- Automatically detects images in the folder
- Saves the output as `output.pdf`
- `fpdf` library is used
